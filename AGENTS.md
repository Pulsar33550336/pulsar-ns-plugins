# AGENTS.md

- Plugin code is Luau, entry points declared in `plugin.toml`; the host calls
  `update` / `onClick` / `onIpc` / `onOpen` / `onClose` when present.
- Validate before pushing: `python3 .github/workflows/scripts/validate-plugins.py`
  (needs `langdetect`; `PyGithub-requirement.txt` lists the full set used by CI).
- `catalog.toml` is generated by CI — never hand-edit or commit it deliberately.
- `screenshot-overlay/` is a standalone Rust crate with its own `default.nix`;
  build it with `nix-build ./screenshot-overlay`, or via `callPackage` from a
  NixOS/home-manager config.
- Translations live under `translations/<locale>.json`, nested objects only, keys
  lowercase; dotted keys are rejected by the validator.
